# SKCT 연습

SKCT(SK 종합역량검사) 온라인 시험 화면을 재현한 연습용 웹사이트입니다.
문제는 직접 넣지 않고, **내가 가진 PDF·이미지·문제 풀이 사이트**를 불러와서 실전과 같은 화면에서 시간을 재며 풉니다.

**바로 접속:** https://jinsu1011.github.io/skct-practice/

## 사용법
1. 위 주소로 접속하거나 `index.html`을 크롬으로 엽니다. (설치 필요 없음)
2. **문제 자료**를 고릅니다.
   - **PDF · 이미지**: 파일을 끌어다 놓거나 선택합니다. 영역별 `시작 쪽`, `쪽당 문항 수`를 넣으면 문항을 넘길 때 페이지도 자동으로 넘어갑니다.
   - **웹사이트**: 링커리어 등 문제 페이지 주소를 넣습니다. 시험 화면 안(iframe)에서는 브라우저 보안 정책 때문에 로그인이 되지 않으므로, 로그인이 필요하면 시험 중 `새 창으로 열기`로 연 창에서 로그인합니다.
   - **종이 책**: 문제 영역에 문항 번호만 표시하고 답안지·타이머·메모·계산기만 사용합니다.
3. 영역(언어이해·자료해석·창의수리·언어추리·수열추리)별 문항 수와 시간을 정하고 **시험 시작**을 누릅니다.

## 진행 순서
대기 1분(바로 진행 가능) → 영역마다 **유형 예시 1분** → 본 검사 → 종료 → **내 답안** 확인

## 시험 화면
- 상단 빨간 바: 영역명 / 남은 시간 (1분 이하일 때 깜빡임, 0이 되면 자동 제출) / `일시정지`·`시간 초기화`·`처음으로` 버튼
- 상단 바 아래 가운데: 현재 문항 수(예: 5 / 20)와 진행 게이지
- 왼쪽(약 70%): 문제 영역 + 5지선다 답안(수능처럼 위에서부터 한 줄씩, 줄 전체를 눌러 선택). 다시 누르면 선택이 해제됩니다.
- 답을 고르지 않고 `다음`을 누르면 “돌아올 수 없다”는 확인 팝업이 뜹니다.
- 오른쪽: 메모장/그림판(탭 전환, **문항을 넘기면 지워짐**) + 계산기(**C = 과정·결과 모두 지움**, 계산기를 클릭하면 키보드 입력 가능)

## 내 답안
영역별로 내가 고른 답과 문항별 소요 시간을 보여줍니다. `정답 입력` 칸에 책의 정답을 순서대로 넣으면(예: `32514…`) O/X와 점수가 바로 표시됩니다.
답안은 브라우저(localStorage)에만 저장되며 외부로 전송되지 않습니다.

## 로그인 · 학습 현황 (SKALA)
- **회원가입**: 캠퍼스(광주/울산/판교), 반(1~10반), 이름, 아이디, 비밀번호
- **기록 저장**: 시험이 끝나면 답안·문항별 소요 시간이 자동 저장되고, `정답 입력`으로 채점하면 채점 결과도 저장됩니다.
- **내 학습 현황**: 응시 횟수, 푼 문항, 정답률, 학습 시간, 접속 시간, 영역별 정답률(취약 영역), 날짜별 정답률 추이, 문항 번호별 오답률, 최근 14일 접속 시간, 응시 기록(다시 채점·삭제), CSV 내보내기
- **관리자**: 학생 현황(정렬·캠퍼스/반 필터·검색), 반별 요약, 로그인 기록, 학생별 상세 현황, 비밀번호 초기화·계정 삭제, 가입 코드 설정, 학생 현황·전체 기록 CSV
- **개인정보**: 가입 시 수집·이용 동의, `개인정보 처리 안내`, 회원 탈퇴(계정과 기록 즉시 삭제)

## 운영 가이드
| 상황 | 방법 |
|---|---|
| 수강생만 가입시키기 | 관리자 → **설정** → 가입 코드 저장 후 수강생에게 공유 (비우면 누구나 가입) |
| 학생이 비밀번호를 잊음 | 관리자 → 학생 클릭 → **비밀번호 초기화** |
| 테스트·잘못 만든 계정 정리 | 관리자 → 학생 클릭 → **계정 삭제** |
| 데이터 분석 | 관리자 → **학생 현황 CSV / 전체 기록 CSV** (엑셀에서 바로 열림) |
| DB 구조가 바뀐 업데이트 | Supabase SQL Editor에서 최신 `supabase/schema.sql`을 다시 Run (기존 데이터는 유지) |

## 시험모드 버튼 (링커리어 등 로그인이 필요한 사이트)
처음 화면 → `웹사이트` 탭의 빨간 **SKCT 시험모드** 버튼을 즐겨찾기 바로 끌어다 놓고, 로그인한 문제 페이지에서 누르면 그 페이지가 시험 화면으로 바뀝니다. 끝나면 `저장하고 채점하기`로 기록을 사이트에 저장합니다.

## 서버 설정 (Supabase, 무료)
1. https://supabase.com 에서 새 프로젝트를 만듭니다. (Region: Northeast Asia (Seoul))
2. **SQL Editor**에 [`supabase/schema.sql`](supabase/schema.sql) 전체를 붙여넣고 Run.
3. 관리자 계정 SQL(`supabase/admin.sql`, 비밀번호가 들어 있어 저장소에는 올리지 않음)을 같은 방법으로 Run.
4. **Project Settings → API**의 Project URL과 anon(publishable) 키를 [`js/config.js`](js/config.js)에 넣습니다.

`js/config.js`가 비어 있으면 로그인 없이 기록이 브라우저에만 저장되는 오프라인 모드로 동작합니다.
무료 프로젝트는 7일 동안 접속이 없으면 일시 중지되며, Supabase 대시보드에서 다시 켤 수 있습니다.
