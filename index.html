1문제 자료

영역별로 주소가 다르면 아래 표의 주소 칸에 각각 입력하세요. 이 방식은 시험 화면 안에서 로그인이 되지 않습니다(브라우저 보안 정책).

로그인이 필요한 사이트(링커리어 등)는 ‘시험모드 버튼’을 쓰세요

시험모드 버튼은 즐겨찾기 바에 저장해 두는 버튼입니다. 문제 페이지에서 누르면 그 페이지가 그대로 시험 화면으로 바뀌어 로그인 상태가 유지됩니다.

  1. 즐겨찾기 바를 켭니다. (크롬: ⌘+Shift+B / 윈도우: Ctrl+Shift+B)
  2. 아래 빨간 버튼을 마우스로 즐겨찾기 바에 끌어다 놓습니다. (클릭이 아니라 드래그)
    SKCT 시험모드← 이 버튼을 즐겨찾기 바로 드래그
  3. 링커리어에 평소처럼 로그인하고 문제 페이지를 엽니다.
  4. 즐겨찾기 바의 SKCT 시험모드를 누르고 영역·문항 수·시간을 고른 뒤 시작합니다.
  5. 끝나면 [저장하고 채점하기]를 눌러 이 사이트에 기록을 저장합니다.

문제 영역에는 현재 문항 번호만 크게 표시됩니다. 종이 문제집을 풀면서 타이머·답안지·메모·계산기만 쓸 때 고르세요.
